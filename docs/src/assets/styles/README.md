# Styles

This directory defines the application's dark-first, monospace, terminal-like
theme. Files are scoped by BEM selector namespace. `app.css` is the shared
global entry stylesheet and imports `_variables.css`. Components import their
own matching stylesheets; those stylesheets consume the custom properties
declared by `_variables.css` without importing it themselves.

| File                 | Visual and theme role                                                                                                                                           | Import or use relationship                                                                                                                                       |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `_variables.css`     | Defines dark-theme defaults and `.light-theme` overrides for color, cards, borders, shadows, typography, transitions, and status colors.                        | Provides custom properties used throughout the directory; imported directly by `app.css`.                                                                        |
| `app.css`            | Establishes the global reset, page background, base typography, app shell, header/content layout, responsive spacing, and shared `spin` and `blink` animations. | Imports `_variables.css`; supplies variables and keyframes used by scoped styles.                                                                                |
| `action-buttons.css` | Styles the stacked action panel and rectangular, outlined action buttons, including hover, active, focus, icon, and processing states.                          | Uses shared color, spacing, typography, and transition variables; scopes to `.buttons-panel` and `.action-button`.                                               |
| `app-header.css`     | Styles the fixed application header, title, user status indicator, accent rule, and bracketed logout control.                                                   | Uses shared card, border, accent, status, and typography variables; scopes to `.app-header`.                                                                     |
| `dashboard.css`      | Defines the desktop two-column dashboard, responsive single-column layout, login card, action panel, and data panel.                                            | Uses shared card, border, accent, shadow, and typography variables; scopes to `.dashboard` and `.dashboard-login`.                                               |
| `data-card.css`      | Styles reusable content cards, loading overlays, hover elevation, list titles, action controls, and edit/delete confirmation modals.                            | Uses shared card, border, primary, error, text, and typography variables; scopes to `.data-card`.                                                                |
| `data-display.css`   | Styles data-loading, empty, error, feedback, result-detail, bulk-action, and component-header states.                                                           | Uses shared colors and typography plus the `spin` keyframe from `app.css`; scopes to `.data-display`.                                                            |
| `error-page.css`     | Centers the full-viewport error view and gives its action button a standalone blue treatment.                                                                   | Scopes to `.error-page`, `.error-details`, and `.error-button`; it does not directly import another stylesheet.                                                  |
| `list-chips.css`     | Styles selectable list chips, checkbox areas, empty and informational messages, and success/error feedback.                                                     | Uses shared primary, accent, card, success, error, disabled, and typography variables; scopes to `.list-chips`.                                                  |
| `list-form.css`      | Styles the list editor form, field validation, action row, primary/cancel/delete buttons, and feedback.                                                         | Uses shared form-related color variables where available, with local fallbacks; scopes to `.list-form`.                                                          |
| `login-form.css`     | Styles the monospace login form, prompt marker, inputs, hint popover, bracketed submit control, and validation messaging.                                       | Uses shared variables and the `blink` keyframe from `app.css`; defines a local `fadeIn` keyframe; scopes to `.login-form`.                                       |
| `pagination.css`     | Styles top and bottom pagination bands, page information, navigation buttons, and disabled states.                                                              | Uses shared primary, text, and typography variables; scopes to `.pagination`.                                                                                    |
| `theme-toggle.css`   | Styles the compact theme-toggle button and its 24 by 24 icon container, with different SVG filters for light and non-light themes.                              | Uses shared accent, border, text, transition, and typography variables; its `.theme-toggle__svg` rules support the theme icons in the sibling `icons` directory. |

Most component styles depend on the variables from `_variables.css` being
available through the global stylesheet. Their selector namespaces keep their
visual rules isolated while preserving one shared theme palette.
