# Public Assets

Nuxt serves files in this directory directly from the site root at runtime. These
assets do not pass through the application bundle or router.

| File          | Public URL     | Browser/runtime role                                                                 |
| ------------- | -------------- | ------------------------------------------------------------------------------------ |
| `favicon.ico` | `/favicon.ico` | The site's favicon, requested by browsers for tabs, bookmarks, and other browser UI. |
| `robots.txt`  | `/robots.txt`  | Crawler policy file. It is currently blank, so it supplies no crawler directives.    |
